## 1. Info

### 설명

- 이메일과 비밀번호를 입력받아 로그인을 처리합니다.
- 이메일이 존재하지 않거나 비밀번호가 일치하지 않으면 로그인에 실패합니다.
- 로그인 성공 시 JWT Access Token을 반환합니다.
- 인증이 필요 없는 공개 API입니다.

---

## 2. Request

### Request Headers

| Key           | Value            | 필수 여부 | 설명         |
|---------------|------------------|-------|------------|
| Content-Type  | application/json | ✅     | 요청 Body 형식 |
| Authorization | 없음               | ❌     | 인증 불필요     |

### PathVariable

없음

### Query Parameter

없음

### Request Body

```json
{
  "email": "user@example.com",
  "password": "password123"
}
```

### Request Field

| 필드명      | 타입     | 필수 여부 | 검증 조건           | 설명   |
|----------|--------|-------|-----------------|------|
| email    | String | ✅     | NotBlank, Email | 이메일  |
| password | String | ✅     | NotBlank        | 비밀번호 |

### Request Example

```
POST /api/login
Content-Type: application/json
```

---

## 3. Response

### 200 OK

```json
{
  "code": "SUCCESS",
  "data": {
    "accessToken": "eyJhbGciOiJIUzI1NiJ9...",
    "tokenType": "Bearer",
    "expiresIn": 3600
  }
}
```

### Response Field

| 필드명              | 타입     | 설명                       |
|------------------|--------|--------------------------|
| code             | String | 성공 코드. 성공 시 `SUCCESS`    |
| data.accessToken | String | JWT Access Token         |
| data.tokenType   | String | 토큰 타입. 고정값 `Bearer`      |
| data.expiresIn   | long   | Access Token 만료 시간. 초 단위 |

---

## 4. Error Response

### 400 Bad Request

요청값 검증에 실패한 경우입니다.

```json
{
  "code": "COMMON_001",
  "message": "email: 이메일 형식이 올바르지 않습니다."
}
```

### 401 Unauthorized

이메일이 존재하지 않거나 비밀번호가 일치하지 않는 경우입니다.

```json
{
  "code": "AUTH_004",
  "message": "이메일 또는 비밀번호가 올바르지 않습니다."
}
```

### 500 Internal Server Error

서버 내부 오류가 발생한 경우입니다.

```json
{
  "code": "COMMON_002",
  "message": "서버 내부 오류가 발생했습니다."
}
```

## 5. 처리 흐름

```
AuthController.login()
  → AuthService.login()
  → AuthRepository.findByEmail()
  → 이메일 존재 여부 확인
  → PasswordEncoder.matches()
  → 비밀번호 일치 여부 확인
  → JwtTokenProvider.createToken()
  → LoginResponseDto.of()
  → ApiResponse.ok(responseDto)
```
