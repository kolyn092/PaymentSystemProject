## 1. Info

### 설명

- 이메일, 비밀번호, 이름, 전화번호를 입력받아 회원을 생성합니다.
- 이미 사용 중인 이메일이면 회원가입에 실패합니다.
- 비밀번호는 암호화하여 저장합니다.
- 회원가입 성공 시 생성된 회원의 `memberId`, `email`, `name`을 반환합니다.
- 인증이 필요 없는 공개 API입니다.

---

## 2. Request

### Request Headers

| Key           | Value            | 필수 여부 | 설명         |
|---------------|------------------|-------|------------|
| Content-Type  | application/json | ✅     | 요청 Body 형식 |
| Authorization | 없음               | ❌     | 인증 불필요     |

### PathVariable

없음

### Query Parameter

없음

### Request Body

```json
{
  "email": "user@example.com",
  "password": "password123",
  "name": "홍길동",
  "phone": "010-1234-5678"
}
```

### Request Field

| 필드명      | 타입     | 필수 여부 | 검증 조건                         | 설명                       |
|----------|--------|-------|-------------------------------|--------------------------|
| email    | String | ✅     | NotBlank, Email               | 이메일                      |
| password | String | ✅     | NotBlank, Size(min=8, max=64) | 비밀번호                     |
| name     | String | ✅     | NotBlank, Size(max=50)        | 이름                       |
| phone    | String | ✅     | NotBlank, Pattern             | 전화번호. `010-1234-5678` 형식 |

### Request Example

```
POST /api/signup
Content-Type: application/json
```

---

## 3. Response

### 201 Created

```json
{
  "code": "SUCCESS",
  "data": {
    "memberId": 1,
    "email": "user@example.com",
    "name": "홍길동"
  }
}
```

### Response Field

| 필드명           | 타입     | 설명                    |
|---------------|--------|-----------------------|
| code          | String | 성공 코드. 성공 시 `SUCCESS` |
| data.memberId | Long   | 생성된 회원 ID             |
| data.email    | String | 회원 이메일                |
| data.name     | String | 회원 이름                 |

---

## 4. Error Response

### 400 Bad Request

요청값 검증에 실패한 경우입니다.

```json
{
  "code": "COMMON_001",
  "message": "email: 이메일 형식이 올바르지 않습니다."
}
```

### 409 Conflict

이미 사용 중인 이메일인 경우입니다.

```json
{
  "code": "AUTH_003",
  "message": "이미 사용 중인 이메일입니다."
}
```

### 500 Internal Server Error

서버 내부 오류가 발생한 경우입니다.

```json
{
  "code": "COMMON_002",
  "message": "서버 내부 오류가 발생했습니다."
}
```

## 5. 처리 흐름

```
AuthController.signup()
  → AuthService.signup()
  → AuthRepository.existsByEmail()
  → 이메일 중복 여부 확인
  → PasswordEncoder.encode()
  → Member 생성
  → AuthRepository.save()
  → SignupResponseDto.from()
  → ApiResponse.ok(responseDto)
```
