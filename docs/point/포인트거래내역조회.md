## 1. Info

### 설명

- 현재 로그인한 회원의 포인트 거래 내역을 페이지 단위로 조회합니다.
- 포인트 거래 내역은 생성일 기준 최신순으로 조회됩니다.
- 페이지 번호는 `0`부터 시작합니다.
- 거래 내역이 없어도 API 오류가 아니며, `transactions: []` 형태로 정상 응답됩니다.
- 응답에는 `balanceAfter`, `description` 필드가 없습니다.
- 현재 코드 기준으로 인증이 필요한 API입니다.

---

## 2. Request

### Request Headers

| Key           | Value                | 필수 여부 | 설명        |
|---------------|----------------------|-------|-----------|
| Authorization | Bearer {accessToken} | ✅     | JWT 인증 토큰 |

### PathVariable

없음

### Query Parameter

| 파라미터명 | 타입  | 필수 여부 | 기본값 | 설명                 |
|-------|-----|-------|-----|--------------------|
| page  | int | ❌     | 0   | 페이지 번호. `0`부터 시작   |
| size  | int | ❌     | 10  | 한 페이지에 조회할 거래 내역 수 |

### Request Body

없음

### Request Example

```
GET /api/points/transactions?page=0&size=5
Authorization: Bearer {accessToken}
```

## 3. Response

### 200 OK

```json
{
  "code": "SUCCESS",
  "data": {
    "transactions": [
      {
        "pointTransactionId": 1,
        "type": "EARN",
        "amount": 3500,
        "createdAt": "2026-06-08T10:30:00"
      },
      {
        "pointTransactionId": 2,
        "type": "USE",
        "amount": -1000,
        "createdAt": "2026-06-08T10:20:00"
      }
    ],
    "page": 0,
    "size": 5,
    "totalElements": 2,
    "totalPages": 1
  }
}
```

### 빈 거래 내역 정상 응답 예시

```json
{
  "code": "SUCCESS",
  "data": {
    "transactions": [],
    "page": 0,
    "size": 5,
    "totalElements": 0,
    "totalPages": 0
  }
}
```

### Response Field

| 필드명                                    | 타입            | 설명                    |
|----------------------------------------|---------------|-----------------------|
| code                                   | String        | 성공 코드. 성공 시 `SUCCESS` |
| data.transactions                      | Array         | 포인트 거래 내역 목록          |
| data.transactions[].pointTransactionId | Long          | 포인트 거래 내역 ID          |
| data.transactions[].type               | String        | 포인트 거래 타입             |
| data.transactions[].amount             | Integer       | 포인트 변동 금액             |
| data.transactions[].createdAt          | LocalDateTime | 포인트 거래 생성일            |
| data.page                              | int           | 현재 페이지 번호. `0`부터 시작   |
| data.size                              | int           | 페이지 크기                |
| data.totalElements                     | long          | 전체 포인트 거래 내역 수        |
| data.totalPages                        | int           | 전체 페이지 수              |

### Point Transaction Type

| 타입          | 설명        | amount 부호 |
|-------------|-----------|-----------|
| EARN        | 포인트 적립    | 양수        |
| USE         | 포인트 사용    | 음수        |
| REFUND_USE  | 사용 포인트 환급 | 양수        |
| CANCEL_EARN | 적립 포인트 회수 | 음수        |

## 4. Error Response

### 400 Bad Request

`page`가 0보다 작거나 `size`가 1보다 작은 경우입니다.

```json
{
  "code": "COMMON_001",
  "message": "입력값이 올바르지 않습니다."
}
```

### 401 Unauthorized

인증 토큰이 없거나 인증되지 않은 요청인 경우입니다.

```json
{
  "code": "AUTH_001",
  "message": "인증이 필요합니다."
}
```

### 500 Internal Server Error

서버 내부 오류가 발생한 경우입니다.

```json
{
  "code": "COMMON_002",
  "message": "서버 내부 오류가 발생했습니다."
}
```

## 5. 처리 흐름

```
PointController.getPointTransactions()
  → @AuthenticationPrincipal CustomUserDetails에서 memberId 추출
  → PointService.getPointTransactions()
  → page, size 값 검증
  → PageRequest.of(page, size)
  → PointRepository.findAllByMember_IdOrderByCreatedAtDesc()
  → 현재 로그인한 회원의 포인트 거래 내역을 최신순으로 조회
  → Page<PointTransaction>을 GetPointTransactionsResponseDto로 변환
  → PointTransactionDetail.from()
  → ApiResponse.ok(responseDto)
```
