## 1. Info

### 설명

- 현재 로그인한 회원의 포인트 잔액을 조회합니다.
- 포인트 잔액은 별도 지갑 테이블이 아니라 `member.point_balance` 값을 기준으로 조회합니다.
- 응답 필드명은 `pointBalance`가 아니라 `balance`입니다.
- 현재 코드 기준으로 인증이 필요한 API입니다.

---

## 2. Request

### Request Headers

| Key           | Value                | 필수 여부 | 설명        |
|---------------|----------------------|-------|-----------|
| Authorization | Bearer {accessToken} | ✅     | JWT 인증 토큰 |

### PathVariable

없음

### Query Parameter

없음

### Request Body

없음

### Request Example

```
GET /api/points/balance
Authorization: Bearer {accessToken}
```

---

## 3. Response

### 200 OK

```json
{
  "code": "SUCCESS",
  "data": {
    "balance": 10000
  }
}
```

### Response Field

| 필드명          | 타입      | 설명                    |
|--------------|---------|-----------------------|
| code         | String  | 성공 코드. 성공 시 `SUCCESS` |
| data.balance | Integer | 현재 로그인한 회원의 포인트 잔액    |

---

## 4. Error Response

### 401 Unauthorized

인증 토큰이 없거나 인증되지 않은 요청인 경우입니다.

```json
{
  "code": "AUTH_001",
  "message": "인증이 필요합니다."
}
```

### 404 Not Found

토큰의 회원 ID에 해당하는 회원을 찾을 수 없는 경우입니다.

```json
{
  "code": "AUTH_005",
  "message": "회원을 찾을 수 없습니다."
}
```

### 500 Internal Server Error

서버 내부 오류가 발생한 경우입니다.

```json
{
  "code": "COMMON_002",
  "message": "서버 내부 오류가 발생했습니다."
}
```

---

## 5. 처리 흐름

```
PointController.getPointBalance()
  → @AuthenticationPrincipal CustomUserDetails에서 memberId 추출
  → PointService.getPointBalance()
  → MemberRepository.findById()
  → 회원 존재 여부 확인
  → GetPointBalanceResponseDto.from()
  → Member.pointBalance 값을 balance로 변환
  → ApiResponse.ok(responseDto)
```
