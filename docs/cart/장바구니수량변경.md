## 1. Info

### 설명

- 현재 로그인한 회원의 장바구니 상품 수량을 변경합니다.
- 장바구니 항목 ID가 아니라 `productId`로 변경할 상품을 찾습니다.
- 변경 수량은 `1` 이상이어야 합니다.
- 변경 수량이 상품 재고보다 많으면 요청에 실패합니다.
- 현재 코드 기준으로 인증이 필요한 API입니다.

---

## 2. Request

### Request Headers

| Key           | Value                | 필수 여부 | 설명         |
|---------------|----------------------|-------|------------|
| Content-Type  | application/json     | ✅     | 요청 Body 형식 |
| Authorization | Bearer {accessToken} | ✅     | JWT 인증 토큰  |

### PathVariable

없음

### Query Parameter

없음

### Request Body

```json
{
  "productId": 1,
  "quantity": 3
}
```

### Request Field

| 필드명       | 타입   | 필수 여부 | 검증 조건   | 설명            |
|-----------|------|-------|---------|---------------|
| productId | Long | ✅     | NotNull | 수량을 변경할 상품 ID |
| quantity  | int  | ✅     | Min(1)  | 변경할 수량. 1 이상  |

### Request Example

```
PATCH /api/cartitems
Content-Type: application/json
Authorization: Bearer {accessToken}
```

---

## 3. Response

### 200 OK

```json
{
  "code": "SUCCESS",
  "data": "수량이 성공적으로 변경되었습니다."
}
```

### Response Field

| 필드명  | 타입     | 설명                    |
|------|--------|-----------------------|
| code | String | 성공 코드. 성공 시 `SUCCESS` |
| data | String | 수량 변경 성공 메시지          |

---

## 4. Error Response

### 400 Bad Request

요청값 검증에 실패한 경우입니다.

```json
{
  "code": "COMMON_001",
  "message": "quantity: 수량은 1 이상이어야 합니다"
}
```

### 400 Bad Request

변경 수량이 상품 재고 수량을 초과한 경우입니다.

```json
{
  "code": "CART_103",
  "message": "상품의 재고 수량을 초과하여 담을 수 없습니다."
}
```

### 401 Unauthorized

인증 토큰이 없거나 인증되지 않은 요청인 경우입니다.

```json
{
  "code": "AUTH_001",
  "message": "인증이 필요합니다."
}
```

### 404 Not Found

현재 로그인한 회원의 장바구니에서 해당 상품을 찾을 수 없는 경우입니다.

```json
{
  "code": "CART_101",
  "message": "장바구니 항목을 찾을 수 없습니다."
}
```

### 500 Internal Server Error

서버 내부 오류가 발생한 경우입니다.

```json
{
  "code": "COMMON_002",
  "message": "서버 내부 오류가 발생했습니다."
}
```

## 5. 처리 흐름

```
CartController.updateQuantity()
  → CartService.updateQuantity()
  → CartItemRepository.findByMember_idAndProduct_Id()
  → 현재 로그인한 회원의 장바구니에서 productId에 해당하는 항목 조회
  → CartItem.changeQuantity()
  → 수량이 1 이상인지 확인
  → 변경 수량이 상품 재고 이하인지 확인
  → 장바구니 항목 수량 변경
  → ApiResponse.ok("수량이 성공적으로 변경되었습니다.")
```
