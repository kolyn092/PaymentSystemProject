## 1. Info

### 설명

- 현재 로그인한 회원의 장바구니 항목 중 선택한 항목만 조회합니다.
- 선택한 장바구니 항목 ID 목록은 Query Parameter `ids`로 전달합니다.
- 선택한 항목들의 상품 정보, 수량, 재고, 생성일, 수정일을 반환합니다.
- 선택한 상품들의 총 금액을 `totalPrice`로 반환합니다.
- `ids`가 없거나 빈 값이면 API 오류가 아니며, `cartItems: []`, `totalPrice: 0` 형태로 정상 응답됩니다.
- 현재 코드 기준으로 인증이 필요한 API입니다.

---

## 2. Request

### Request Headers

| Key           | Value                | 필수 여부 | 설명        |
|---------------|----------------------|-------|-----------|
| Authorization | Bearer {accessToken} | ✅     | JWT 인증 토큰 |

### PathVariable

없음

### Query Parameter

| 파라미터명 | 타입   | 필수 여부 | 설명                |
|-------|------|-------|-------------------|
| ids   | List | ❌     | 조회할 장바구니 항목 ID 목록 |

### Request Body

없음

### Request Example

```
GET /api/cartitems/selected?ids=1&ids=2
Authorization: Bearer {accessToken}
```

### 빈 선택 목록 Request Example

```
GET /api/cartitems/selected
Authorization: Bearer {accessToken}
```

### Response Field

| 필드명                          | 타입            | 설명                                      |
|------------------------------|---------------|-----------------------------------------|
| code                         | String        | 성공 코드. 성공 시 `SUCCESS`                   |
| data.cartItems               | Array         | 선택한 장바구니 상품 목록                          |
| data.cartItems[].id          | Long          | 장바구니 항목 ID                              |
| data.cartItems[].productId   | Long          | 상품 ID                                   |
| data.cartItems[].productName | String        | 상품명                                     |
| data.cartItems[].price       | int           | 상품 가격                                   |
| data.cartItems[].quantity    | int           | 장바구니에 담긴 수량                             |
| data.cartItems[].stock       | int           | 현재 상품 재고 수량                             |
| data.cartItems[].createdAt   | LocalDateTime | 장바구니 항목 생성일                             |
| data.cartItems[].updatedAt   | LocalDateTime | 장바구니 항목 수정일                             |
| data.totalPrice              | int           | 선택한 장바구니 상품 총 금액. `price * quantity` 합계 |

## 4. Error Response

### 401 Unauthorized

인증 토큰이 없거나 인증되지 않은 요청인 경우입니다.

```json
{
  "code": "AUTH_001",
  "message": "인증이 필요합니다."
}
```

### 404 Not Found

요청한 장바구니 항목 중 존재하지 않거나, 현재 로그인한 회원의 장바구니 항목이 아닌 항목이 포함된 경우입니다.

```json
{
  "code": "CART_101",
  "message": "장바구니 항목을 찾을 수 없습니다."
}
```

### 500 Internal Server Error

서버 내부 오류가 발생한 경우입니다.

```json
{
  "code": "COMMON_002",
  "message": "서버 내부 오류가 발생했습니다."
}
```

## 5. 처리 흐름

```
CartController.getSelectedItems()
  → CartService.getSelectedItems()
  → ids가 null이거나 비어 있는지 확인

  [ids가 없거나 비어 있는 경우]
  → 빈 cartItems 목록과 totalPrice 0 반환
  → ApiResponse.ok(responseDto)

  [ids가 있는 경우]
  → CartItemRepository.findByMemberIdAndIdIn()
  → 현재 로그인한 회원의 장바구니 항목 중 ids에 해당하는 항목 조회
  → 요청한 ids 개수와 조회된 항목 개수 비교
  → 개수가 다르면 CART_ITEM_NOT_FOUND 예외 발생
  → CartItem 목록을 GetCartItemResponseDto로 변환
  → 각 항목의 price * quantity 합산
  → GetCartResponseDto 생성
  → ApiResponse.ok(responseDto)
```
