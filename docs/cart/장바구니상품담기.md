## 1. Info

### 설명

- 현재 로그인한 회원의 장바구니에 상품을 담습니다.
- 이미 같은 상품이 장바구니에 있으면 새 항목을 만들지 않고 기존 장바구니 항목의 수량을 증가시킵니다.
- 상품 ID가 존재하지 않으면 요청에 실패합니다.
- 현재 코드 기준으로 인증이 필요한 API입니다.

---

## 2. Request

### Request Headers

| Key           | Value                | 필수 여부 | 설명         |
|---------------|----------------------|-------|------------|
| Content-Type  | application/json     | ✅     | 요청 Body 형식 |
| Authorization | Bearer {accessToken} | ✅     | JWT 인증 토큰  |

### PathVariable

없음

### Query Parameter

없음

### Request Body

```json
{
  "productId": 1,
  "quantity": 2
}
```

### Request Field

| 필드명       | 타입   | 필수 여부 | 검증 조건   | 설명                |
|-----------|------|-------|---------|-------------------|
| productId | Long | ✅     | NotNull | 장바구니에 담을 상품 ID    |
| quantity  | int  | ✅     | Min(1)  | 장바구니에 담을 수량. 1 이상 |

### Request Example

```
POST /api/cartitems
Content-Type: application/json
Authorization: Bearer {accessToken}
```

---

## 3. Response

### 201 Created

```json
{
  "code": "SUCCESS",
  "data": {
    "cartItemId": 1,
    "productId": 1,
    "quantity": 2,
    "createdAt": "2026-06-08T10:30:00",
    "updatedAt": "2026-06-08T10:30:00"
  }
}
```

### Response Field

| 필드명             | 타입            | 설명                    |
|-----------------|---------------|-----------------------|
| code            | String        | 성공 코드. 성공 시 `SUCCESS` |
| data.cartItemId | Long          | 장바구니 항목 ID            |
| data.productId  | Long          | 상품 ID                 |
| data.quantity   | int           | 장바구니에 담긴 수량           |
| data.createdAt  | LocalDateTime | 장바구니 항목 생성일           |
| data.updatedAt  | LocalDateTime | 장바구니 항목 수정일           |

## 4. Error Response

### 400 Bad Request

요청값 검증에 실패한 경우입니다.

```json
{
  "code": "COMMON_001",
  "message": "quantity: 수량은 1 이상이어야 합니다"
}
```

### 400 Bad Request

이미 장바구니에 있는 상품의 수량을 추가할 때, 기존 수량과 추가 수량의 합이 상품 재고를 초과한 경우입니다.

```json
{
  "code": "CART_103",
  "message": "상품의 재고 수량을 초과하여 담을 수 없습니다."
}
```

### 401 Unauthorized

인증 토큰이 없거나 인증되지 않은 요청인 경우입니다.

```json
{
  "code": "AUTH_001",
  "message": "인증이 필요합니다."
}
```

### 404 Not Found

토큰의 회원 ID에 해당하는 회원을 찾을 수 없는 경우입니다.

```json
{
  "code": "AUTH_005",
  "message": "회원을 찾을 수 없습니다."
}
```

### 404 Not Found

상품 ID에 해당하는 상품을 찾을 수 없는 경우입니다.

```json
{
  "code": "PRODUCT_051",
  "message": "상품을 찾을 수 없습니다."
}
```

### 500 Internal Server Error

서버 내부 오류가 발생한 경우입니다.

```json
{
  "code": "COMMON_002",
  "message": "서버 내부 오류가 발생했습니다."
}
```

## 5. 처리 흐름

```
CartController.addItem()
  → CartService.addItem()
  → CartItemRepository.findByMember_idAndProduct_Id()
  → 이미 같은 상품이 장바구니에 있는지 확인

  [이미 장바구니에 있는 경우]
  → CartItem.addQuantity()
  → 기존 수량에 요청 수량 추가
  → AddCartResponseDto.from()
  → ApiResponse.ok(responseDto)

  [장바구니에 없는 경우]
  → MemberRepository.findById()
  → ProductRepository.findById()
  → CartItem.from()
  → CartItemRepository.save()
  → AddCartResponseDto.from()
  → ApiResponse.ok(responseDto)
```
