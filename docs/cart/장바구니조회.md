## 1. Info

### 설명

- 현재 로그인한 회원의 전체 장바구니 상품 목록을 조회합니다.
- 각 장바구니 항목의 상품 정보, 수량, 재고, 생성일, 수정일을 반환합니다.
- 장바구니 상품들의 총 금액을 `totalPrice`로 반환합니다.
- 장바구니가 비어 있어도 API 오류가 아니며, `cartItems: []`, `totalPrice: 0` 형태로 정상 응답됩니다.
- 현재 코드 기준으로 인증이 필요한 API입니다.

## 3. Response

### 200 OK

```json
{
  "code": "SUCCESS",
  "data": {
    "cartItems": [
      {
        "id": 1,
        "productId": 1,
        "productName": "기계식 키보드",
        "price": 150000,
        "quantity": 2,
        "stock": 10,
        "createdAt": "2026-06-08T10:30:00",
        "updatedAt": "2026-06-08T10:30:00"
      }
    ],
    "totalPrice": 300000
  }
}
```

### 빈 장바구니 정상 응답 예시

```json
{
  "code": "SUCCESS",
  "data": {
    "cartItems": [],
    "totalPrice": 0
  }
}
```

### Response Field

| 필드명                          | 타입            | 설명                                  |
|------------------------------|---------------|-------------------------------------|
| code                         | String        | 성공 코드. 성공 시 `SUCCESS`               |
| data.cartItems               | Array         | 장바구니 상품 목록                          |
| data.cartItems[].id          | Long          | 장바구니 항목 ID                          |
| data.cartItems[].productId   | Long          | 상품 ID                               |
| data.cartItems[].productName | String        | 상품명                                 |
| data.cartItems[].price       | int           | 상품 가격                               |
| data.cartItems[].quantity    | int           | 장바구니에 담긴 수량                         |
| data.cartItems[].stock       | int           | 현재 상품 재고 수량                         |
| data.cartItems[].createdAt   | LocalDateTime | 장바구니 항목 생성일                         |
| data.cartItems[].updatedAt   | LocalDateTime | 장바구니 항목 수정일                         |
| data.totalPrice              | int           | 장바구니 상품 총 금액. `price * quantity` 합계 |

---

## 4. Error Response

### 401 Unauthorized

인증 토큰이 없거나 인증되지 않은 요청인 경우입니다.

```json
{
  "code": "AUTH_001",
  "message": "인증이 필요합니다."
}
```

### 500 Internal Server Error

서버 내부 오류가 발생한 경우입니다.

```json
{
  "code": "COMMON_002",
  "message": "서버 내부 오류가 발생했습니다."
}
```

## 5. 처리 흐름

```
CartController.getItems()
  → CartService.getCartItems()
  → CartItemRepository.findByMemberId()
  → 현재 로그인한 회원의 장바구니 항목 조회
  → CartItem 목록을 GetCartItemResponseDto로 변환
  → 각 항목의 price * quantity 합산
  → GetCartResponseDto 생성
  → ApiResponse.ok(responseDto)
```
