## 1. Info

### 설명

- 현재 로그인한 회원의 장바구니 상품을 전체 삭제합니다.
- 장바구니에 삭제할 항목이 없으면 요청에 실패합니다.
- 현재 코드 기준으로 인증이 필요한 API입니다.

---

## 2. Request

### Request Headers

| Key           | Value                | 필수 여부 | 설명        |
|---------------|----------------------|-------|-----------|
| Authorization | Bearer {accessToken} | ✅     | JWT 인증 토큰 |

### PathVariable

없음

### Query Parameter

없음

### Request Body

없음

### Request Example

```
DELETE /api/cartitems
Authorization: Bearer {accessToken}
```

---

## 3. Response

### 200 OK

```json
{
  "code": "SUCCESS",
  "data": "장바구니가 모두 비워졌습니다."
}
```

### Response Field

| 필드명  | 타입     | 설명                    |
|------|--------|-----------------------|
| code | String | 성공 코드. 성공 시 `SUCCESS` |
| data | String | 장바구니 전체 비우기 성공 메시지    |

---

## 4. Error Response

### 401 Unauthorized

인증 토큰이 없거나 인증되지 않은 요청인 경우입니다.

```json
{
  "code": "AUTH_001",
  "message": "인증이 필요합니다."
}
```

### 404 Not Found

현재 로그인한 회원의 장바구니에 삭제할 항목이 없는 경우입니다.

```json
{
  "code": "CART_101",
  "message": "장바구니 항목을 찾을 수 없습니다."
}
```

### 500 Internal Server Error

서버 내부 오류가 발생한 경우입니다.

```json
{
  "code": "COMMON_002",
  "message": "서버 내부 오류가 발생했습니다."
}
```

---

## 5. 처리 흐름

```
CartController.removeCart()
  → CartService.removeCart()
  → CartItemRepository.deleteAllByMemberId()
  → 삭제된 row 수 확인

  [삭제된 row 수가 0인 경우]
  → CART_ITEM_NOT_FOUND 예외 발생

  [삭제 성공한 경우]
  → ApiResponse.ok("장바구니가 모두 비워졌습니다.")
```
