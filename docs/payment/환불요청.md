## 1. Info

### 설명

- 현재 로그인한 회원의 주문에 대해 환불을 요청합니다.
- 실제 URL은 `/api/orders/{orderId}/refunds`입니다.
- 결제 완료된 주문만 환불할 수 있습니다.
- 부분 환불과 전체 환불을 모두 지원합니다.
- 환불할 주문 상품 ID와 수량을 `items`로 전달합니다.
- 동일한 `orderItemId`를 한 요청 안에 중복으로 넣을 수 없습니다.
- 환불 수량은 잔여 환불 가능 수량을 초과할 수 없습니다.
- 환불 성공 시 환불 기록과 환불 상품 기록을 저장합니다.
- 환불된 상품 수량만큼 상품 재고를 복구합니다.
- 결제 때 사용했던 포인트는 환불 비율에 따라 반환됩니다.
- 결제 때 적립했던 포인트는 환불 비율에 따라 회수됩니다.
- PG 환불 금액이 있는 경우 DB 환불 처리 후 PortOne PG 취소 요청을 보냅니다.
- 현재 코드 기준으로 인증이 필요한 API입니다.

## 2. Request

### Request Headers

| Key           | Value                | 필수 여부 | 설명         |
|---------------|----------------------|-------|------------|
| Content-Type  | application/json     | ✅     | 요청 Body 형식 |
| Authorization | Bearer {accessToken} | ✅     | JWT 인증 토큰  |

### PathVariable

| 변수명     | 타입   | 필수 여부 | 설명           |
|---------|------|-------|--------------|
| orderId | Long | ✅     | 환불 요청할 주문 ID |

### Query Parameter

없음

### Request Body

```json
{
  "items": [
    {
      "orderItemId": 1,
      "quantity": 1
    },
    {
      "orderItemId": 2,
      "quantity": 1
    }
  ],
  "reason": "단순 변심"
}
```

### Request Field

| 필드명                 | 타입      | 필수 여부 | 검증 조건                   | 설명             |
|---------------------|---------|-------|-------------------------|----------------|
| items               | Array   | ✅     | NotEmpty, Valid         | 환불할 주문 상품 목록   |
| items[].orderItemId | Long    | ✅     | NotNull                 | 환불할 주문 상품 ID   |
| items[].quantity    | Integer | ✅     | NotNull, Positive       | 환불 수량. 1 이상    |
| reason              | String  | ✅     | NotBlank, Size(max=500) | 환불 사유. 최대 500자 |

### Request Example

```
POST /api/orders/1/refunds
Content-Type: application/json
Authorization: Bearer {accessToken}
```

## 3. Response

### 201 Created

```json
{
  "code": "SUCCESS",
  "data": {
    "refundId": 1,
    "orderId": 1,
    "refundStatus": "COMPLETED",
    "totalRefundAmount": 200000,
    "pointRefundAmount": 10000,
    "pgRefundAmount": 190000,
    "reason": "단순 변심",
    "refundedItems": [
      {
        "orderItemId": 1,
        "productName": "기계식 키보드",
        "quantity": 1,
        "refundAmount": 150000
      },
      {
        "orderItemId": 2,
        "productName": "무선 마우스",
        "quantity": 1,
        "refundAmount": 50000
      }
    ],
    "createdAt": "2026-06-08T10:30:00"
  }
}
```

### Response Field

| 필드명                               | 타입            | 설명                                            |
|-----------------------------------|---------------|-----------------------------------------------|
| code                              | String        | 성공 코드. 성공 시 `SUCCESS`                         |
| data.refundId                     | Long          | 생성된 환불 ID                                     |
| data.orderId                      | Long          | 환불 대상 주문 ID                                   |
| data.refundStatus                 | String        | 환불 상태. 현재 생성 시 `COMPLETED`                    |
| data.totalRefundAmount            | Integer       | 총 환불 금액. `pointRefundAmount + pgRefundAmount` |
| data.pointRefundAmount            | Integer       | 포인트 환불 금액                                     |
| data.pgRefundAmount               | Integer       | PG 환불 금액                                      |
| data.reason                       | String        | 환불 사유                                         |
| data.refundedItems                | Array         | 환불 상품 목록                                      |
| data.refundedItems[].orderItemId  | Long          | 환불된 주문 상품 ID                                  |
| data.refundedItems[].productName  | String        | 주문 당시 상품명                                     |
| data.refundedItems[].quantity     | Integer       | 환불 수량                                         |
| data.refundedItems[].refundAmount | Integer       | 해당 상품의 총 환불 금액                                |
| data.createdAt                    | LocalDateTime | 환불 생성일                                        |

## 4. Error Response

### 400 Bad Request

요청값 검증에 실패한 경우입니다.

```json
{
  "code": "COMMON_001",
  "message": "환불 상품 목록은 필수입니다."
}
```

### 400 Bad Request

결제 완료된 주문이 아니어서 환불할 수 없는 경우입니다.

```json
{
  "code": "ORDER_007",
  "message": "결제 완료된 주문만 환불할 수 있습니다."
}
```

### 400 Bad Request

잔여 환불 가능 수량을 초과한 경우입니다.

```json
{
  "code": "REFUND_001",
  "message": "잔여 환불 가능 수량을 초과했습니다."
}
```

### 400 Bad Request

이미 전체 환불된 주문에 다시 환불을 요청한 경우입니다.

```json
{
  "code": "REFUND_002",
  "message": "이미 전체 환불된 주문입니다."
}
```

### 400 Bad Request

한 요청 안에 동일한 주문 상품 ID가 중복으로 들어온 경우입니다.

```json
{
  "code": "REFUND_003",
  "message": "동일한 주문 상품은 한 번만 환불 요청할 수 있습니다."
}
```

### 400 Bad Request

환불 금액이 현재 PG 취소 가능 금액을 초과한 경우입니다.

```json
{
  "code": "COMMON_001",
  "message": "입력값이 올바르지 않습니다."
}
```

### 400 Bad Request

결제 상태 변경이 불가능한 상태인 경우입니다.

```json
{
  "code": "PAYMENT_003",
  "message": "변경할 수 없는 결제 상태입니다."
}
```

### 401 Unauthorized

인증 토큰이 없거나 인증되지 않은 요청인 경우입니다.

```json
{
  "code": "AUTH_001",
  "message": "인증이 필요합니다."
}
```

### 404 Not Found

주문 ID에 해당하는 결제 정보가 없거나, 현재 로그인한 회원의 주문에 연결된 결제가 아닌 경우입니다.

```json
{
  "code": "PAYMENT_004",
  "message": "결제를 찾을 수 없습니다."
}
```

### 404 Not Found

요청한 주문 상품 ID가 해당 주문에 존재하지 않는 경우입니다.

```json
{
  "code": "ORDER_006",
  "message": "주문 상품을 찾을 수 없습니다."
}
```

### 500 Internal Server Error

서버 내부 오류가 발생한 경우입니다.

```json
{
  "code": "COMMON_002",
  "message": "서버 내부 오류가 발생했습니다."
}
```

## 5. 처리 흐름

```
RefundController.createRefund()
  → @AuthenticationPrincipal CustomUserDetails에서 memberId 추출
  → RefundFacade.createRefund()
  → RefundService.processRefund()

  → validateDuplicateRefundItems()
  → 요청 items 안에 동일한 orderItemId가 중복되는지 확인
  → 중복이면 DUPLICATE_REFUND_ITEM 예외 발생

  → PaymentService.findByOrderIdAndMemberId()
  → 주문 ID와 현재 로그인한 회원 ID로 Payment 조회
  → 결제 정보 존재 여부 및 본인 주문 여부 확인

  → PaymentService.validateRefundablePayment()
  → Payment 상태가 REFUNDED이면 ALREADY_REFUNDED 예외 발생
  → Payment 상태가 COMPLETED 또는 PARTIAL_REFUNDED가 아니면 ORDER_NOT_PAID 예외 발생

  → createRefundItemCalculations()
  → 각 요청 item마다 OrderItemService.findOrderItemForRefund()
  → orderItemId와 orderId로 주문 상품 조회
  → OrderItemService.validateRefundableQuantity()
  → 기존 환불 수량을 제외한 잔여 환불 가능 수량 확인
  → 요청 수량이 잔여 환불 가능 수량을 초과하면 EXCEED_REFUNDABLE_QUANTITY 예외 발생

  → RefundCalculator.calculateItemRefundAmount()
  → 상품별 환불 금액 계산
  → RefundCalculator.calculatePointRefundAmount()
  → 결제 때 사용한 포인트 비율에 따라 포인트 환불 금액 계산
  → RefundCalculator.calculatePgRefundAmount()
  → 상품별 PG 환불 금액 계산

  → 총 포인트 환불 금액 계산
  → 총 PG 환불 금액 계산
  → 총 환불 금액 계산

  → RefundRepository.sumPgRefundAmountByPaymentId()
  → 현재 PG 취소 가능 금액 계산
  → 이번 PG 환불 금액이 취소 가능 금액보다 크면 INVALID_INPUT 예외 발생

  → RefundRepository.sumRefundAmountByPaymentId()
  → 기존 누적 환불 금액 조회
  → 이번 환불 이후 전체 환불인지 부분 환불인지 판단

  [전체 환불인 경우]
  → Payment 상태를 REFUNDED로 변경
  → OrderService.cancelByFullRefund()
  → 주문 상태를 CANCELLED로 변경

  [부분 환불인 경우]
  → Payment 상태가 COMPLETED라면 PARTIAL_REFUNDED로 변경

  → Refund.createCompletedRefund()
  → RefundRepository.save()
  → 환불 기록 저장

  → RefundItem.createRefundItem()
  → RefundItemRepository.save()
  → 환불 상품 기록 저장

  → OrderItemService.restoreStock()
  → 환불 수량만큼 상품 재고 복구

  → PointService.refundUsedPoint()
  → 결제 때 사용했던 포인트 중 환불 대상 금액 비율만큼 회원에게 반환
  → PointService.cancelEarnedPoint()
  → 결제 때 적립했던 포인트 중 환불 대상 금액 비율만큼 회수

  → CreateRefundResponseDto.from()
  → RefundProcessResult 반환

  → RefundFacade.tryCancelPgRefund()

  [PG 환불 금액이 0인 경우]
  → PortOne PG 취소 요청 없이 종료

  [PG 환불 금액이 0보다 큰 경우]
  → PortOneRefundService.cancelPayment()
  → PortOne PG 취소 요청

  → ApiResponse.ok(responseDto)
```
