## 1. Info

### 설명

- 클라이언트에서 PortOne 결제창을 띄우기 위해 필요한 설정값을 조회합니다.
- 현재 코드 기준 실제 URL은 `/api/config/portone`입니다.
- `storeId`, `channelKey`를 반환합니다.
- `apiSecret`, `webhookSecret` 같은 서버 전용 비밀값은 반환하지 않습니다.
- JWT 인증이 필요 없는 공개 API입니다.

---

## 2. Request

### Request Headers

| Key           | Value | 필수 여부 | 설명     |
|---------------|-------|-------|--------|
| Authorization | 없음    | ❌     | 인증 불필요 |

### PathVariable

없음

### Query Parameter

없음

### Request Body

없음

### Request Example

```
GET /api/config/portone
```

---

## 3. Response

### 200 OK

```json
{
  "code": "SUCCESS",
  "data": {
    "storeId": "store-xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx",
    "channelKey": "channel-key-xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"
  }
}
```

### Response Field

| 필드명             | 타입     | 설명                    |
|-----------------|--------|-----------------------|
| code            | String | 성공 코드. 성공 시 `SUCCESS` |
| data.storeId    | String | PortOne 스토어 ID        |
| data.channelKey | String | PortOne 채널 키          |

---

## 4. Error Response

### 500 Internal Server Error

서버 내부 오류가 발생한 경우입니다.

```json
{
  "code": "COMMON_002",
  "message": "서버 내부 오류가 발생했습니다."
}
```

---

## 5. 처리 흐름

```
PortOneConfigController.getConfig()
  → PortOneProperties에서 storeId 조회
  → PortOneProperties에서 channelKey 조회
  → PortOneConfigResponseDto 생성
  → ApiResponse.ok(responseDto)
```
