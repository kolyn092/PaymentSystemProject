## 1. Info

### 설명

- 현재 로그인한 회원의 결제를 취소합니다.
- 주문 ID를 기준으로 결제 정보를 조회합니다.
- 본인의 주문에 연결된 결제만 취소할 수 있습니다.
- 현재 코드 기준으로 결제 상태가 `PENDING`인 경우에만 취소할 수 있습니다.
- 결제 취소 성공 시 결제 상태는 `CANCELED`, 주문 상태는 `CANCELLED`로 변경됩니다.
- 주문 생성 단계에서 선차감했던 상품 재고가 복구됩니다.
- 포인트 전액 결제가 아닌 경우 PortOne 결제 취소 요청도 함께 보냅니다.
- 현재 코드 기준으로 인증이 필요한 API입니다.

## 2. Request

### Request Headers

| Key           | Value                | 필수 여부 | 설명        |
|---------------|----------------------|-------|-----------|
| Authorization | Bearer {accessToken} | ✅     | JWT 인증 토큰 |

### PathVariable

| 변수명     | 타입   | 필수 여부 | 설명            |
|---------|------|-------|---------------|
| orderId | Long | ✅     | 결제를 취소할 주문 ID |

### Query Parameter

없음

### Request Body

없음

### Request Example

```
POST /api/payments/1/cancel
Authorization: Bearer {accessToken}
```

  "code": "SUCCESS"

| 필드명  | 타입     | 설명                    |
|------|--------|-----------------------|

## 4. Error Response

### 400 Bad Request

결제 상태가 `PENDING`이 아니어서 취소할 수 없는 경우입니다.

```json
{
  "code": "PAYMENT_005",
  "message": "이미 결제를 완료하였습니다."
}
```

### 400 Bad Request

주문 상태가 `PENDING_PAYMENT`가 아니어서 취소할 수 없는 경우입니다.

```json
{
  "code": "ORDER_004",
  "message": "유효하지 않은 주문 상태입니다."
}
```

### 401 Unauthorized

인증 토큰이 없거나 인증되지 않은 요청인 경우입니다.

```json
{
  "code": "AUTH_001",
  "message": "인증이 필요합니다."
}
```

### 404 Not Found

주문 ID에 해당하는 결제 정보가 없거나, 현재 로그인한 회원의 주문에 연결된 결제가 아닌 경우입니다.

```json
{
  "code": "PAYMENT_004",
  "message": "결제를 찾을 수 없습니다."
}
```

### 500 Internal Server Error

서버 내부 오류가 발생한 경우입니다.

```json
{
  "code": "COMMON_002",
  "message": "서버 내부 오류가 발생했습니다."
}
```

## 5. 처리 흐름

```
PaymentController.cancelPayment()
  → @AuthenticationPrincipal CustomUserDetails에서 memberId 추출
  → PaymentFacade.cancelPayment()
  → PaymentService.findByOrderIdAndMemberId()
  → 주문 ID와 현재 로그인한 회원 ID로 Payment 조회
  → 결제 정보 존재 여부 및 본인 주문 여부 확인
  → PaymentCommandService.cancelPayment()
  → PaymentRepository.findByOrderIdWithOrderForUpdate()
  → 결제 상태 확인

  [이미 CANCELED 상태인 경우]
  → 그대로 성공 처리

  [PENDING 상태가 아닌 경우]
  → ALREADY_PROCESSED_PAYMENT 예외 발생

  [PENDING 상태인 경우]
  → Payment.markAsCanceled()
  → 결제 상태를 CANCELED로 변경
  → Order.cancel()
  → 주문 상태가 PENDING_PAYMENT인지 확인
  → 주문 상품 수량만큼 상품 재고 복구
  → 주문 상태를 CANCELLED로 변경

  [포인트 전액 결제가 아닌 경우]
  → PaymentGateway.cancelPayment()
  → PortOne 결제 취소 요청

  → ApiResponse.ok()
```
