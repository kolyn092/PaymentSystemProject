## 1. Info

### 설명

- 현재 로그인한 회원의 주문을 취소합니다.
- 본인의 주문만 취소할 수 있습니다.
- 주문 상태가 `PENDING_PAYMENT`인 경우에만 취소할 수 있습니다.
- 주문 취소 시 주문 생성 단계에서 선차감했던 상품 재고를 복구합니다.
- 주문 취소 성공 시 주문 상태는 `CANCELLED`로 변경됩니다.
- 주문과 연결된 결제 상태는 `FAILED`로 변경됩니다.
- 현재 코드 기준으로 인증이 필요한 API입니다.

---

## 2. Request

### Request Headers

| Key           | Value                | 필수 여부 | 설명        |
|---------------|----------------------|-------|-----------|
| Authorization | Bearer {accessToken} | ✅     | JWT 인증 토큰 |

### PathVariable

| 변수명     | 타입   | 필수 여부 | 설명        |
|---------|------|-------|-----------|
| orderId | Long | ✅     | 취소할 주문 ID |

### Query Parameter

없음

### Request Body

없음

### Request Example

```
POST /api/orders/1/cancel
Authorization: Bearer {accessToken}
```

---

## 3. Response

### 200 OK

```json
{
  "code": "SUCCESS",
  "data": {
    "orderId": 1,
    "status": "CANCELLED"
  }
}
```

### Response Field

| 필드명          | 타입     | 설명                      |
|--------------|--------|-------------------------|
| code         | String | 성공 코드. 성공 시 `SUCCESS`   |
| data.orderId | Long   | 취소된 주문 ID               |
| data.status  | String | 취소 후 주문 상태. `CANCELLED` |

---

## 4. Error Response

### 400 Bad Request

주문 상태가 `PENDING_PAYMENT`가 아니어서 취소할 수 없는 경우입니다.

```json
{
  "code": "ORDER_004",
  "message": "유효하지 않은 주문 상태입니다."
}
```

### 401 Unauthorized

인증 토큰이 없거나 인증되지 않은 요청인 경우입니다.

```json
{
  "code": "AUTH_001",
  "message": "인증이 필요합니다."
}
```

### 404 Not Found

주문 ID에 해당하는 주문이 없거나, 현재 로그인한 회원의 주문이 아닌 경우입니다.

```json
{
  "code": "ORDER_003",
  "message": "주문을 찾을 수 없습니다."
}
```

### 404 Not Found

주문에 연결된 결제 정보를 찾을 수 없는 경우입니다.

```json
{
  "code": "PAYMENT_004",
  "message": "결제를 찾을 수 없습니다."
}
```

### 500 Internal Server Error

서버 내부 오류가 발생한 경우입니다.

```json
{
  "code": "COMMON_002",
  "message": "서버 내부 오류가 발생했습니다."
}
```

## 5. 처리 흐름

```
OrderController.cancelOrder()
  → OrderFacade.cancelOrder()
  → OrderService.cancelOrder()
  → OrderRepository.findByIdAndMemberIdWithOrderItems()
  → 주문 존재 여부 및 본인 주문 여부 확인
  → Order.cancel()
  → 주문 상태가 PENDING_PAYMENT인지 확인
  → 주문 상품 수량만큼 상품 재고 복구
  → 주문 상태를 CANCELLED로 변경
  → PaymentService.findByOrderIdWithOrder()
  → 주문에 연결된 결제 정보 조회
  → payment.changeStatus(PaymentStatus.FAILED)
  → CancelOrderResponseDto.from()
  → ApiResponse.ok(responseDto)
```
