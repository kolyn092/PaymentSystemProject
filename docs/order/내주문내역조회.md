## 1. Info

### 설명

- 현재 로그인한 회원의 주문 내역을 페이지 단위로 조회합니다.
- 주문은 `createdAt` 기준 최신순으로 조회됩니다.
- 페이지 번호는 `0`부터 시작합니다.
- 주문 내역이 없더라도 API 오류가 아니며, `content: []` 형태로 정상 응답됩니다.
- 현재 코드 기준으로 인증이 필요한 API입니다.

---

## 2. Request

### Request Headers

| Key           | Value                | 필수 여부 | 설명        |
|---------------|----------------------|-------|-----------|
| Authorization | Bearer {accessToken} | ✅     | JWT 인증 토큰 |

### PathVariable

없음

### Query Parameter

| 파라미터명 | 타입  | 필수 여부 | 기본값 | 설명               |
|-------|-----|-------|-----|------------------|
| page  | int | ❌     | 0   | 페이지 번호. `0`부터 시작 |
| size  | int | ❌     | 20  | 한 페이지에 조회할 주문 수  |

### Request Body

없음

### Request Example

```
GET /api/orders?page=0&size=20
Authorization: Bearer {accessToken}
```

### Response Field

| 필드명                        | 타입            | 설명                    |
|----------------------------|---------------|-----------------------|
| code                       | String        | 성공 코드. 성공 시 `SUCCESS` |
| data.content               | Array         | 주문 내역 목록              |
| data.content[].orderId     | Long          | 주문 ID                 |
| data.content[].orderNumber | String        | 주문 번호                 |
| data.content[].status      | String        | 주문 상태                 |
| data.content[].totalAmount | Integer       | 주문 총 금액               |
| data.content[].createdAt   | LocalDateTime | 주문 생성일                |
| data.totalElements         | Long          | 전체 주문 수               |
| data.totalPages            | Integer       | 전체 페이지 수              |
| data.size                  | Integer       | 페이지 크기                |
| data.number                | Integer       | 현재 페이지 번호. `0`부터 시작   |
| data.first                 | Boolean       | 첫 페이지 여부              |
| data.last                  | Boolean       | 마지막 페이지 여부            |
| data.numberOfElements      | Integer       | 현재 페이지의 주문 개수         |
| data.empty                 | Boolean       | 현재 페이지가 비어 있는지 여부     |

## 4. Error Response

### 401 Unauthorized

인증 토큰이 없거나 인증되지 않은 요청인 경우입니다.

```json
{
  "code": "AUTH_001",
  "message": "인증이 필요합니다."
}
```

### 404 Not Found

토큰의 회원 ID에 해당하는 회원을 찾을 수 없는 경우입니다.

```json
{
  "code": "AUTH_005",
  "message": "회원을 찾을 수 없습니다."
}
```

### 500 Internal Server Error

서버 내부 오류가 발생한 경우입니다.

```json
{
  "code": "COMMON_002",
  "message": "서버 내부 오류가 발생했습니다."
}
```

## 5. 처리 흐름

```
OrderController.getOrderList()
  → OrderFacade.getOrderList()
  → MemberService.findById()
  → 현재 로그인한 회원 조회
  → OrderService.getOrderList()
  → PageRequest.of(page, size, Sort.by(DESC, "createdAt"))
  → OrderRepository.findByMember()
  → Order 목록을 GetOrderListResponseDto로 변환
  → Page<GetOrderListResponseDto> 반환
  → ApiResponse.ok(responseDto)
```
