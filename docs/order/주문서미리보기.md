## 1. Info

### 설명

- 현재 로그인한 회원의 장바구니 상품을 기준으로 주문서 미리보기를 조회합니다.
- `cartItemIds`를 전달하면 선택한 장바구니 항목만 기준으로 주문서를 미리보기합니다.
- `cartItemIds`를 전달하지 않으면 현재 로그인한 회원의 전체 장바구니 항목을 기준으로 주문서를 미리보기합니다.
- 상품별 금액과 총 주문 금액, 현재 보유 포인트를 반환합니다.
- 장바구니가 비어 있으면 요청에 실패합니다.
- 현재 코드 기준으로 인증이 필요한 API입니다.

---

## 2. Request

### Request Headers

| Key           | Value                | 필수 여부 | 설명        |
|---------------|----------------------|-------|-----------|
| Authorization | Bearer {accessToken} | ✅     | JWT 인증 토큰 |

### PathVariable

없음

### Query Parameter

| 파라미터명       | 타입   | 필수 여부 | 설명                                            |
|-------------|------|-------|-----------------------------------------------|
| cartItemIds | List | ❌     | 주문서 미리보기에 포함할 장바구니 항목 ID 목록. 미입력 시 전체 장바구니 기준 |

### Request Body

없음

### Request Example

```
GET /api/orders/preview
Authorization: Bearer {accessToken}
```

### 선택 상품 주문서 미리보기 Request Example

```
GET /api/orders/preview?cartItemIds=1&cartItemIds=2
Authorization: Bearer {accessToken}
```

## 3. Response

### 200 OK

```json
{
  "code": "SUCCESS",
  "data": {
    "items": [
      {
        "productId": 1,
        "productName": "기계식 키보드",
        "price": 150000,
        "quantity": 2,
        "subtotal": 300000
      },
      {
        "productId": 2,
        "productName": "무선 마우스",
        "price": 50000,
        "quantity": 1,
        "subtotal": 50000
      }
    ],
    "totalAmount": 350000,
    "pointBalance": 10000
  }
}
```

### Response Field

| 필드명                      | 타입      | 설명                            |
|--------------------------|---------|-------------------------------|
| code                     | String  | 성공 코드. 성공 시 `SUCCESS`         |
| data.items               | Array   | 주문서 미리보기 상품 목록                |
| data.items[].productId   | Long    | 상품 ID                         |
| data.items[].productName | String  | 상품명                           |
| data.items[].price       | Integer | 상품 가격                         |
| data.items[].quantity    | Integer | 장바구니에 담긴 수량                   |
| data.items[].subtotal    | Integer | 상품별 합계 금액. `price * quantity` |
| data.totalAmount         | Integer | 전체 주문 금액                      |
| data.pointBalance        | Integer | 현재 로그인한 회원의 보유 포인트            |

## 4. Error Response

### 400 Bad Request

장바구니가 비어 있는 경우입니다.

```json
{
  "code": "ORDER_002",
  "message": "장바구니가 비어 있습니다."
}
```

### 401 Unauthorized

인증 토큰이 없거나 인증되지 않은 요청인 경우입니다.

```json
{
  "code": "AUTH_001",
  "message": "인증이 필요합니다."
}
```

### 404 Not Found

토큰의 회원 ID에 해당하는 회원을 찾을 수 없는 경우입니다.

```json
{
  "code": "AUTH_005",
  "message": "회원을 찾을 수 없습니다."
}
```

### 404 Not Found

요청한 장바구니 항목 중 존재하지 않거나, 현재 로그인한 회원의 장바구니 항목이 아닌 항목이 포함된 경우입니다.

```json
{
  "code": "CART_101",
  "message": "장바구니 항목을 찾을 수 없습니다."
}
```

### 500 Internal Server Error

서버 내부 오류가 발생한 경우입니다.

```json
{
  "code": "COMMON_002",
  "message": "서버 내부 오류가 발생했습니다."
}
```

## 5. 처리 흐름

```
OrderController.getOrderPreview()
  → OrderFacade.getOrderPreview()
  → MemberService.findById()
  → 현재 로그인한 회원 조회
  → cartItemIds 존재 여부 확인

  [cartItemIds가 없거나 비어 있는 경우]
  → CartService.findCartEntities()
  → 현재 로그인한 회원의 전체 장바구니 항목 조회

  [cartItemIds가 있는 경우]
  → CartService.findCartEntitiesById()
  → 현재 로그인한 회원의 장바구니 항목 중 cartItemIds에 해당하는 항목 조회
  → 요청한 cartItemIds 개수와 조회된 항목 개수 비교

  → 장바구니가 비어 있으면 CART_EMPTY 예외 발생
  → 선택한 장바구니 항목이 일부 존재하지 않으면 CART_ITEM_NOT_FOUND 예외 발생
  → CartItem 목록을 GetOrderPreviewItemDto로 변환
  → subtotal 합산으로 totalAmount 계산
  → 회원의 pointBalance 포함
  → GetOrderPreviewResponseDto 반환
  → ApiResponse.ok(responseDto)
```
