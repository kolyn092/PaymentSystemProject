## 1. Info

### 설명

- 현재 로그인한 회원의 특정 주문 상세 정보를 조회합니다.
- 주문 기본 정보, 주문 상품 목록, 결제 정보를 함께 반환합니다.
- 본인의 주문이 아니거나 존재하지 않는 주문이면 조회에 실패합니다.
- 현재 코드 기준으로 인증이 필요한 API입니다.

---

## 2. Request

### Request Headers

| Key           | Value                | 필수 여부 | 설명        |
|---------------|----------------------|-------|-----------|
| Authorization | Bearer {accessToken} | ✅     | JWT 인증 토큰 |

### PathVariable

| 변수명     | 타입   | 필수 여부 | 설명        |
|---------|------|-------|-----------|
| orderId | Long | ✅     | 조회할 주문 ID |

### Query Parameter

없음

### Request Body

없음

### Request Example

```
GET /api/orders/1
Authorization: Bearer {accessToken}
```

| data.orderNumber              | String        | 주문 번호                         |
| data.status                   | String        | 주문 상태                         |

| data.earnedPoint              | Integer       | 적립 포인트                        |

| data.orderitems[].orderItemId | Long          | 주문 상품 ID                      |
| data.orderitems[].productName | String        | 주문 당시 상품명                     |
| data.orderitems[].price       | Integer       | 주문 당시 상품 가격                   |
| data.orderitems[].quantity    | Integer       | 주문 수량                         |
| data.orderitems[].subtotal    | Integer       | 상품별 합계 금액. `price * quantity` |
| data.payment                  | Object        | 결제 정보                         |
| data.payment.paymentId        | Long          | 결제 ID                         |
| data.payment.portonePaymentId | String        | 포트원 결제 ID                     |
| data.payment.status           | String        | 결제 상태                         |
| data.payment.paidAt           | LocalDateTime | 결제 완료 시각. 미결제 상태면 `null`      |
| data.createdAt                | LocalDateTime | 주문 생성일                        |

## 4. Error Response

### 401 Unauthorized

인증 토큰이 없거나 인증되지 않은 요청인 경우입니다.

```json
{
  "code": "AUTH_001",
  "message": "인증이 필요합니다."
}
```

### 404 Not Found

주문 ID에 해당하는 주문이 없거나, 현재 로그인한 회원의 주문이 아닌 경우입니다.

```json
{
  "code": "ORDER_003",
  "message": "주문을 찾을 수 없습니다."
}
```

### 404 Not Found

주문에 연결된 결제 정보를 찾을 수 없는 경우입니다.

```json
{
  "code": "PAYMENT_004",
  "message": "결제를 찾을 수 없습니다."
}
```

### 500 Internal Server Error

서버 내부 오류가 발생한 경우입니다.

```json
{
  "code": "COMMON_002",
  "message": "서버 내부 오류가 발생했습니다."
}
```

## 5. 처리 흐름

```
OrderController.getOrderDetail()
  → OrderFacade.getOrderDetail()
  → OrderService.getOrderDetail()
  → OrderRepository.findByIdAndMemberIdWithOrderItems()
  → 주문 존재 여부 및 본인 주문 여부 확인
  → PaymentService.findByOrderIdWithOrder()
  → 주문에 연결된 결제 정보 조회
  → OrderItem 목록을 OrderItemDetailDto로 변환
  → Payment를 OrderPaymentDetailDto로 변환
  → GetOrderDetailResponseDto.from()
  → ApiResponse.ok(responseDto)
```
