## 1. Info

### 설명

- 상품 목록을 페이지 단위로 조회합니다.
- 카테고리, 최소 가격, 최대 가격, 상품 상태로 필터링할 수 있습니다.
- 페이지 번호는 `0`부터 시작합니다.
- 조회 결과가 없더라도 API 오류가 아니며, `content: []` 형태로 정상 응답됩니다.
- 현재 코드 기준으로 인증이 필요한 API입니다.

---

## 2. Request

### Request Headers

| Key           | Value                | 필수 여부 | 설명        |
|---------------|----------------------|-------|-----------|
| Authorization | Bearer {accessToken} | ✅     | JWT 인증 토큰 |

### PathVariable

없음

### Query Parameter

| 파라미터명    | 타입      | 필수 여부 | 기본값        | 설명                  |
|----------|---------|-------|------------|---------------------|
| category | String  | ❌     | 없음         | 상품 카테고리             |
| minPrice | Integer | ❌     | 없음         | 최소 가격               |
| maxPrice | Integer | ❌     | 없음         | 최대 가격               |
| status   | String  | ❌     | 없음         | 상품 상태               |
| page     | Integer | ❌     | 0          | 페이지 번호. `0`부터 시작    |
| size     | Integer | ❌     | 10         | 한 페이지에 조회할 상품 수     |
| sort     | String  | ❌     | price,DESC | 정렬 기준. 기본값은 가격 내림차순 |

### Request Body

없음

### Request Example

```
GET /api/products?page=0&size=10
Authorization: Bearer {accessToken}
```

### 필터링 Request Example

```
GET /api/products?category=ELECTRONIC&minPrice=10000&maxPrice=200000&status=ON_SALE&page=0&size=10
Authorization: Bearer {accessToken}
```

## 3. Response

### 200 OK

```json
{
  "code": "SUCCESS",
  "data": {
    "content": [
      {
        "id": 1,
        "name": "기계식 키보드",
        "price": 150000,
        "stock": 10,
        "status": "ON_SALE",
        "category": "ELECTRONIC",
        "createdAt": "2026-06-08T10:30:00",
        "updatedAt": "2026-06-08T10:30:00"
      }
    ],
    "pageNumber": 0,
    "pageSize": 10,
    "totalElements": 1,
    "totalPage": 1
  }
}
```

### 빈 목록 정상 응답 예시

```json
{
  "code": "SUCCESS",
  "data": {
    "content": [],
    "pageNumber": 0,
    "pageSize": 10,
    "totalElements": 0,
    "totalPage": 0
  }
}
```

### Response Field

| 필드명                      | 타입            | 설명                    |
|--------------------------|---------------|-----------------------|
| code                     | String        | 성공 코드. 성공 시 `SUCCESS` |
| data.content             | Array         | 상품 목록                 |
| data.content[].id        | Long          | 상품 ID                 |
| data.content[].name      | String        | 상품명                   |
| data.content[].price     | Integer       | 상품 가격                 |
| data.content[].stock     | Integer       | 상품 재고 수량              |
| data.content[].status    | String        | 상품 상태                 |
| data.content[].category  | String        | 상품 카테고리               |
| data.content[].createdAt | LocalDateTime | 상품 생성일                |
| data.content[].updatedAt | LocalDateTime | 상품 수정일                |
| data.pageNumber          | Integer       | 현재 페이지 번호             |
| data.pageSize            | Integer       | 페이지 크기                |
| data.totalElements       | Long          | 전체 상품 수               |
| data.totalPage           | Integer       | 전체 페이지 수              |

## 4. Error Response

### 401 Unauthorized

인증 토큰이 없거나 인증되지 않은 요청인 경우입니다.

```json
{
  "code": "AUTH_001",
  "message": "인증이 필요합니다."
}
```

### 500 Internal Server Error

서버 내부 오류가 발생한 경우입니다.

```json
{
  "code": "COMMON_002",
  "message": "서버 내부 오류가 발생했습니다."
}
```

## 5. 처리 흐름

```
ProductController.list()
  → ProductService.findAll()
  → category / minPrice / maxPrice / status 조건 확인
  → Specification<Product> 조건 생성
  → ProductRepository.findAll(spec, pageable)
  → Product 목록을 GetProductListResponseDto로 변환
  → GetProductPageableResponseDto.from()
  → ApiResponse.ok(responseDto)
```
