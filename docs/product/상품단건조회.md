## 1. Info

### 설명

- 상품 ID로 상품 단건 정보를 조회합니다.
- 존재하지 않는 상품 ID로 요청하면 조회에 실패합니다.
- 현재 코드 기준으로 인증이 필요한 API입니다.

---

## 2. Request

### Request Headers

| Key           | Value                | 필수 여부 | 설명        |
|---------------|----------------------|-------|-----------|
| Authorization | Bearer {accessToken} | ✅     | JWT 인증 토큰 |

### PathVariable

| 변수명 | 타입   | 필수 여부 | 설명        |
|-----|------|-------|-----------|
| id  | Long | ✅     | 조회할 상품 ID |

### Query Parameter

없음

### Request Body

없음

### Request Example

```
GET /api/products/1
Authorization: Bearer {accessToken}
```

---

## 3. Response

### 200 OK

```json
{
  "code": "SUCCESS",
  "data": {
    "id": 1,
    "name": "기계식 키보드",
    "price": 150000,
    "stock": 10,
    "description": "청축 기계식 키보드입니다.",
    "status": "ON_SALE",
    "category": "ELECTRONIC"
  }
}
```

### Response Field

| 필드명              | 타입     | 설명                    |
|------------------|--------|-----------------------|
| code             | String | 성공 코드. 성공 시 `SUCCESS` |
| data.id          | Long   | 상품 ID                 |
| data.name        | String | 상품명                   |
| data.price       | int    | 상품 가격                 |
| data.stock       | int    | 상품 재고 수량              |
| data.description | String | 상품 설명                 |
| data.status      | String | 상품 상태                 |
| data.category    | String | 상품 카테고리               |

---

## 4. Error Response

### 401 Unauthorized

인증 토큰이 없거나 인증되지 않은 요청인 경우입니다.

```json
{
  "code": "AUTH_001",
  "message": "인증이 필요합니다."
}
```

### 404 Not Found

상품 ID에 해당하는 상품을 찾을 수 없는 경우입니다.

```json
{
  "code": "PRODUCT_051",
  "message": "상품을 찾을 수 없습니다."
}
```

### 500 Internal Server Error

서버 내부 오류가 발생한 경우입니다.

```json
{
  "code": "COMMON_002",
  "message": "서버 내부 오류가 발생했습니다."
}
```
